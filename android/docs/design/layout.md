# 布局：手机与 ≥ 840dp

Mac 主窗口默认 1200×800，最小 800×560，侧栏钉在窗口左侧。Android 不把这张 1200×800 画布缩小后居中，也不保留红绿灯和 `--sand-titlebar-block`（44px）拖拽区。

断点用可用窗口宽度，单位 dp：

- **手机**：宽度 `< 840dp`。侧栏不占内容列。内容列就是整窗。
- **分栏**：宽度 `≥ 840dp`。左侧是 Mac 那条侧栏的 dp 宽度，右侧是内容。

安全区（状态栏、导航栏、刘海、手势条）加在相应边的外缘。不把 Mac 的 18px 转录 padding 拿去吃安全区。

## 手机：抽屉替代侧栏

侧栏数据、分组、置顶、搜索、新建、设置与 [screens/sidebar.md](./screens/sidebar.md) 相同。容器换成从起始边滑出的模态抽屉。

| 项 | 规格 |
| --- | --- |
| 宽度 | `min(360dp, 窗口宽度的 86%)`。360 落在 Mac 侧栏上限 400 以内。这是抽屉宽度，不是把 1200 缩成屏宽 |
| 高度 | 整窗，含在安全区之内 |
| 底色 | `--nuum-bg-chrome` |
| 遮罩 | `--sand-bg-scrim`，点遮罩关闭 |
| 开合 | `--nuum-duration-slower` + `--nuum-easing-out-strong`。系统「减弱动态效果」开启时，抽屉直接出现或消失，见 [motion.md](./motion.md) |
| 内容列 | 抽屉打开时内容列保持全宽，被遮罩盖住。内容列不缩小，不平移出一条 88dp 的窄轨 |

Mac 在窄窗口用 `projectResponsiveSidebar`：`available = viewportWidth - 740`，不够就把侧栏收成 88px，好留给大约 740px 的会话。这条 740 是为 1200×800 窗口服务的。手机上不要调用它。88dp 图标轨只在分栏里、并且用户自己把宽度拖过折叠阈值时出现。

手机内容顶栏，高度 `--nuum-spacing-14`（56px）再加状态栏安全区：

| 位置 | 控件 |
| --- | --- |
| 起始 | 图标按钮，热区 48dp，图形盒 `--nuum-height-sm`。`aria` 用 key `Agents`（侧栏的 `aria-label`）。点击打开抽屉 |
| 中间 | 当前表面自己的标题。一对一是资料入口，Room / NunuBar 是工作名 |
| 末端 | 该表面自己的动作。没有就留空 |

冷启动且没有选中的 Nunu、也没有选中的 work：抽屉处于打开，空列表文案可见。关掉抽屉后，内容列仍是空会话，顶栏的 `Agents` 按钮还在，用来再打开抽屉。

系统返回键先关抽屉，再关浮层，再离开当前内容。没有浮层、抽屉也关着时，返回键把内容退回「未选中」，并打开抽屉。

## 分栏：≥ 840dp

横向两栏，中间没有 1200×800 的信箱边。

```text
┌──────────────┬────────────────────────────────────┐
│ 侧栏          │ 内容（会话 / Room / NunuBar / 创建） │
│ 默认 236dp    │ 剩余宽度                             │
└──────────────┴────────────────────────────────────┘
```

侧栏宽度存在 DataStore `nuum-ui`，字段与 Mac `localStorage` key `nuum.ui.sidebar.v2` 相同：`expandedWidth`、`isCollapsed`。

| 常数 | 值 | 来源 |
| --- | --- | --- |
| 默认展开 | `236dp` | `SIDEBAR_LAYOUT_DEFAULTS.expandedWidth` |
| 展开最小 | `220dp` | `minExpandedWidth` |
| 展开最大 | `400dp` | `maxExpandedWidth`，同时不超过内容列所在窗口的 42%（Mac `.sand-agents-sidebar` 的 `max-width: 42vw`） |
| 折叠宽度 | `88dp` | `collapsedWidth` |
| 拖过即折叠 | `< 208dp` | `collapseBelow` |

拖动手柄在侧栏尾缘，竖条热区 48dp 宽，可见线 1dp，颜色 `--sand-border-default`。`aria-label` 用 key `Resize sidebar`。拖动中不写盘；松手后写入，与 `settleSidebarLayout` 相同。Esc 等价于系统返回：取消这次拖动。

分栏顶栏没有 `Agents` 按钮。侧栏一直在。

内容区最小希望值约为 600dp。840dp 窗口减去 220dp 侧栏后仍有 620dp，所以到达断点时不要自动折叠。只有用户把把手拖到 208dp 以下才进入 88dp 轨。88dp 轨里：头像 40dp，隐藏搜索框、名字、预览、时间；新建按钮留在底栏，设置按钮留在底栏。与 Mac `.is-collapsed` 相同。

从手机旋转到 ≥ 840dp：抽屉关掉，侧栏按已保存宽度钉住，内容不重载。从分栏收到 840dp 以下：侧栏收进抽屉，保持关闭，除非当前没有选中项。

## 内容宽度

气泡和卡片的最大宽度跟内容列走，不跟「假设的 1200 画布」走。

| 元素 | 最大宽度 |
| --- | --- |
| 用户消息 | `min(88%, 560dp, 内容列宽度 - 82dp)` |
| 助手栈、工具卡、通知 | `min(88%, 640dp)` |
| widget | 最小 260dp，最大 380dp；手机内容列更窄时最大改为内容列减去 `--nuum-spacing-8`（32dp） |
| 创建 Nunu 卡片 | `min(440dp, 窗口宽度 - 32dp)`；手机改全屏页，见 [screens/create-nunu.md](./screens/create-nunu.md) |
| 设置对话框 | 见 [screens/settings.md](./screens/settings.md) |
| 资料栏 | 手机全屏。≥ 840dp 时贴在内容列尾部，宽度 `clamp(300dp, 内容列的 33%, 420dp)`，左边 1dp `--sand-border-subtle` |

转录列在很宽的分栏里不再继续拉满气泡：气泡已经有 560 / 640 的上限，背景用 `--nuum-bg-editor` 铺满内容列。助手气泡靠起始边，用户气泡靠末端边。

## 资料、设置、目录在两档里的容器

| 表面 | `< 840dp` | `≥ 840dp` |
| --- | --- | --- |
| 资料 | 盖住内容列的全屏页。关闭用 key `Close profile` | 内容列尾部的一栏，会话仍可见 |
| 设置 | 全屏页。General / Models 在页顶横排 | 居中对话框，宽 `min(860dp, 窗口宽度 - 32dp)`。窗口宽度 `< 900dp` 时对话框改为 `窗口 - 32dp` 见方，与 Mac `@media (max-width: 900px)` 相同 |
| 能力目录、任务详情、身份编辑 | 全屏页 | Mac 的 `dialog`，宽沿用各屏规格 |
| Proactive | 全屏页 | 内容列上的全高页，侧栏仍在 |
| peer 抽屉 | 从底部升起的半屏，最高 88% | 内容列内居中的表面，最大 640dp |
| 审批条 | 钉在输入框上方，全宽减去左右 `--nuum-spacing-4` | 同一位置，最大 640dp，靠起始边 |

竖向顺序在手机上是「顶栏 → 滚动内容 → 底栏输入」，分栏上相同，只是左面多了侧栏。不要把 Mac 的三栏（侧栏 + 会话 + 资料）在手机上挤成三列。
