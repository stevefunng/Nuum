# Room / NunuBar 实施与验证

2026-10-15。当前架构见 [foundation.md](./foundation.md)，审阅决策见 [v2-redesign-plan.md](./v2-redesign-plan.md)。本文替换旧实施记录，避免将旧递归调度、接收水位和新同步水位混用。

## 本次已实现

- Room / NunuBar 无 @ 均唤醒。Grokbot 式普通顺序循环集中执行三轮／十条公开消息／每成员每次两条、轮换、提及和沉默停止，不持久化循环位置。
- 连续用户补充合批，已运行成员可完成；明确停止禁止迟到公开写入。停止排队中的讨论不会继续唤醒下一位。
- 房间 timeline 是唯一顺序源，快照携带同一日志前缀的 throughSeq；客户端水位表实际读写并拒绝旧快照回退、错房间覆盖和序号冲突。
- 模型输入使用同房间、同 compact 代际的连续性判断：连续时增量，重新进入时最近 24 条背景，触发消息单独保障。删除永久接收索引和 cursor 写入。群聊经历保存在主 session，UI 只展示参与提示。
- 卡片独立 session，共用原 Nunu 身份及单执行槽；共享 project root 的活动 run 串行。创建 Nunu 固定负责，单个未结清 worker，结果返回负责人，阻塞由人确认。
- 卡片业务事件直接作为来源，执行开始／结束作为恢复证据；不确定工作由用户继续。派工、交付和发言额度耗尽后结束当前 Kernel turn。
- 增加中断原因、继续和显式缩小历史范围入口。修复恢复提示覆盖输入框及启动失败后侧栏仍显示工作中的问题。
- 旧 timeline / cursors 迁移前备份，旧不确定执行人工确认；旧 dispatch 只兼容读取。完整坏行拒绝启动／写入，撕裂尾行备份后修复。
- foundation、重构计划状态及 AGENTS 已统一到当前架构，旧方案不再作为有效设计。

主要实现：Host 的 `room-discussion.ts`、`room-context.ts`、`work-execution.ts`、`runtime.ts`、`work-store.ts`、`scheduler.ts`；UI 的 `room-sync.ts` 与 `work-board.tsx`；Kernel 的 delegated tool `endTurn`。

## 明确边界

- 跨用户身份／权限、传输、共享 session、远端增量补缺及服务端排序部署均为 V3；本期只有可沿用的顺序契约和本地完整快照水位。
- 未做真实模型与外部工具的全链路验收。窗口验证覆盖当前深色布局；浅色和所有窄窗口组合未做完整视觉矩阵验收。
- Context 使用统一保守估算，计入消息封装、工具定义及图片预留，不保证等于各家 tokenizer。通用 compact 已接入后台准备及长 run 边界检查；没有独立房间摘要服务。
- 本次没有新增主 session reset 产品入口；不能据此宣称完整 reset 生命周期已验收。新建 Nunu 的主 session 和卡片新成员代际使用独立输入索引。
- project root 串行只约束 Host 调度的活动 run，不能约束脱离 run 的后台进程、外部应用和所有任意路径；不提供全局文件锁或外部工具 exactly-once。遇不确定执行须先核对副作用再继续。
- 保留卡片业务状态及 CAS，不新增责任转移、接受／拒绝、多 worker 汇合、持久讨论状态机或工具抢占。

## 群聊连续性与 compact 补齐

本轮实现、阈值与限制见 [compact-pipeline.md](./compact-pipeline.md)。新增回归覆盖同群连续／私聊打断／成员代际／compact 后补背景、窗口外触发、长 run 工具边界、后台摘要保留新增结果、取消后迟到摘要、有限重试与分块。实际 Electron 隔离窗口已验证个人会话显示“参与群聊：群聊上下文验收”，不显示内部 Trigger prompt。未调用真实模型，摘要语义保真仍需真实使用验收。

2026-10-16 最终复验：补齐 Kernel 退出时 RPC pending 拒绝与 EPIPE 处理；278 项测试、类型检查、依赖边界和 Host 冒烟通过。

### 2026-10-16 群聊交互验收修正

- 右侧成员点击改为头像左侧的状态气泡，点击外部或 Escape 关闭；移除原私聊浮窗入口。
- 状态预览使用 Host 当前 activeRunId 匹配房间执行记录，显示当前讨论或卡片标题；空闲时不把旧任务、旧回复当作当前工作。没有提供工具级进度百分比或模型生成的进度摘要。
- 团队聊天复用单聊消息气泡及 Markdown 样式；Enter 发送、Shift+Enter 换行，输入法确认候选不发送。
- 核查结果：个人 UI 仍保留“参与群聊”提示，群聊工具活动也可能显示；群聊输入正文不渲染为私人聊天气泡。此次未改变主 session 的持久记忆或该投影规则。
- 全量测试、类型检查、依赖边界检查通过；在实际 Electron 窗口核对了状态气泡位置及群聊气泡样式。
- 后续视觉验收：成员列表隐藏角色文字；状态气泡去掉名称与重复说明，宽度按内容收缩，每次打开轮换四种不对称圆角，支持减少动态效果。已在 Electron 窗口确认空闲态只显示“空闲”。
